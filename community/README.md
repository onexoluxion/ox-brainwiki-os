# Community cabinet preview

Documentation draft; not an installed skill or a release artifact. All example business data, events and decisions are invented.

Start with the [sample project](example/PROJECT_INDEX.md), follow its selected guide, read the evidence, and inspect the dated result. Retrieval locates material; the cabinet establishes authority. Neither grants permission to act.

For an existing project, retain its entry point and records. If navigation is missing, adapt the [index template](templates/PROJECT_INDEX.md) and [task guide template](templates/task-and-source-guide.md); replace every double-braced placeholder before use. Do not add unused directories or relocate records.

[Operations and Calibrate](operations.md) describes review, auto, full and lite. Example requests: `Calibrate review the repeated date omission`, `Calibrate auto the verified operating error`, `Calibrate full after the self-correction`, and `Calibrate lite the configured operating memory`. These are workflow examples, not executable commands.

Use [acceptance cases](acceptance-cases.md) for a fresh read-only reviewer. [Packaging gates](packaging-gates.md) records what remains before distributing an installable skill. No runtime installation or connector configuration is provided here.
