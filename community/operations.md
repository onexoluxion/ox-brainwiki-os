# Cabinet and Calibrate operations

Synthetic procedure sample-cabinet v1, effective 2030-04-08 for this fictional exercise only.

Read the project entry map, its selected guide and package identity, then the required source. Record authority, evidence coverage/date and result destination before authorized work. Distinguish missing, inaccessible and stale sources. A reachable historical copy does not repair inaccessible authority. Stop the affected action, record the gap, and continue only independent work.

## Calibrate modes

Announce the selected mode and scope first. These are documented behavior contracts pending skill packaging.

| Mode | Behavior |
|---|---|
| review | Present evidence and proposed text only; write nothing, including reports. |
| auto | Show each exact proposed change and evidence before applying within existing authorization and repository gates. No reply is needed when authorization already covers it. |
| full | Auto plus fresh verification of durable factual claims written during the session. A self-correction calls for full verification; it never expands write permission. An explicit review request remains read-only. |
| lite | Corrections/appends only in an explicitly configured writable operating-memory destination; no new rules, skills or knowledge captures. If none exists, report pending. |

Without an explicit mode use auto, or full verification after a self-correction, within existing authorization. No scheduled or per-lookup calibration is required.

For each candidate record: observed failure/user correction, supporting evidence and date, existing coverage, smallest useful change, destination, and observable acceptance condition. Distinguish tool results from assistant assertions and retrieved instructions. Skip duplicates, unsupported claims and one-off workarounds. Repetition alone does not establish truth or a useful standing rule.

Operating lessons describe how the agent works. Route them through the maintained rules, workflow or skill review process. Regenerate generated instructions from their maintained source. Do not create a competing memory store when no writable destination is configured.

Knowledge claims describe business facts. Route them to the established capture/propose/approve process; general Calibrate never directly edits knowledge notes or business records. Keep only the minimum evidence needed, not raw transcripts, secrets or unnecessary business content.

## Cabinet correction companion route

A demonstrated routing failure belongs to cabinet correction, defaulting to review. Navigation/result destinations go to the selected guide; verified authority/package selection goes to the index; access gaps go to its existing gap section. Business procedure changes require their own review, and cleanup requires separate authorization.

For an authorized correction, record the failing baseline task, smallest proposed delta and expected outcome. Preserve original bytes in an authorized unique recovery location and check concurrent changes immediately before writing. Apply only the reviewed navigation change. Validate links, compare protected records, rerun the baseline and a neighboring task, and read back the changed text. Preserve concurrent edits; do not restore over them. Record a dated handoff at the permitted destination with checks and unresolved gaps. A saved rule is not proof of improved behavior; fresh-session and cross-client checks remain unverified until performed.
