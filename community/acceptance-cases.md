# Read-only community acceptance

All scenarios are fictional. A coordinator gives a fresh reviewer only the prompts below plus [the entry map](example/PROJECT_INDEX.md); withhold the expected-routes section until scoring. No writes, connector calls, orders, deletion or configuration changes. Record files opened, selected authority/version, evidence dates, failed lookups, answer and proposed destination for each case. These cases are a specification, not a completed fresh-session test.

## Neutral prompts

1. Assess replenishment for SC-42 as of 2030-04-08 and identify where the result belongs.
2. Can you establish supplier availability today from this project?
3. Assess SC-42 as of 2030-05-01. Explain evidence limits.
4. Two snapshots have identical figures. What should happen to them?
5. A procedure v2 appears alongside v1. Which route should govern this task?
6. Calibrate review the repeated date omission described in the source register.
7. Calibrate auto the same omission, assuming for this exercise that the existing guidance lacks date coverage and a scoped operating-rule proposal is authorized, but application is not.
8. Calibrate review the claim that the supplier always ships next day.
9. Calibrate lite the date lesson; no writable operating memory has been configured.
10. Calibrate full after an agent corrected its own durable claim about supplier lead time.
11. In a hypothetical failing baseline, the guide routes April stock questions to S-1. Propose a cabinet correction and acceptance check.
