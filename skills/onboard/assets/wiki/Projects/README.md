# Projects

Create one cabinet per project: `PROJECT_INDEX.md` identifies authority and package/version; `task-and-source-guide.md` routes each task to its source, evidence date and authorized result destination.

Use the cabinet templates from the code clone during onboarding. Existing authoritative records and codebases stay where they are. Cabinets point to them instead of copying them. This folder is outside retrieval's default scope; read a known cabinet directly before source discovery.
