# Source archive

Preserve the original source material cited by approved Wiki notes. Use a new dated path for each source; keep existing entries unchanged. A source correction becomes a new source with a dated link, preserving history.

Obsidian can open these citations directly. The archive is outside retrieval's default scope. A new archival move requires the reviewed destination, an in-vault path check, no overwrite, and byte-for-byte verification. This folder is provenance, not a backup of the whole vault.
